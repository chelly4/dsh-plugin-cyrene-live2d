# 小昔涟 · Live2D 桌宠（dsh-plugin-cyrene-live2d **v0.2.7**）

> **仅支持 Windows。** 需要 DSH `>=0.2.1-rc.1 <0.3.0-0`，Node `>=18`（用 DSH 自带的 node 即可，不需要单独装）。

在 DeepSeek Harness 的 Web GUI 里挂一只昔涟：Live2D 桌宠（点她 / 摸头 / 拖动 / 右键菜单）、
整页主题（三套配色 / 线稿水印 / 开屏 / 首屏封面）、**人设与世界书注入**、
351 条预烧语音（32k opus，可接本机 TTS 现场合成）、余额与每日账本、
关系记忆、提醒 / 便签两个副插件、米游社自动签到。

**0.2.0 起**：整页外观由**内置的「昔涟印象」主题**负责（三套配色 / 轻全两档 / 线稿水印 / 开屏 / 首屏封面），
入口在外观 →「主题」。原来那套粉白皮肤（`SKIN_CSS`）保留但默认让位，主题关掉时才接管。
**整页背景图轮播已下线**（0.2.0 起整页观感交给主题的水印与氛围层）。

**0.2.6（本次）**：
- **新增「Q 版」模型**——解包自 B 站 UP @-----Alone------ 的 Wallpaper Engine 壁纸（见文末第三方来源）。右键/设置里可切；自带待机、抬手、害羞、眨眼，点她的手 / 腿 / 后发会有对应反应。
- **整批重烧 351 条预烧语音**：换成新一代本地 Qwen3-TTS 微调模型，每条台词 12 个候选里挑声纹最像的那条；opus 降到 32 kbps（6.7 MB → 3.8 MB，语音仍清晰）。
- 修正本文档里过时的模型清单与语音条数。

**0.2.3**：内置人设种子同步到最新版（补上一条「技术汇报也别整段滑成我」的自称规则）；关掉早已下线的背景图开关，新装时不会再去画那层。

**0.2.2（本次）**：
- 外观新增「**卡片透度**」四档（标准 / 更透 / 纯透 / 全透）—— 代码块、思考块、工具卡都能透出底图；设置页等弹窗保持实底，不会被聊天内容盖住。
- 主题二级页底部多了一个「**取样**」按钮：点一下再点页面上任意元素，会弹出它的 class 与真实背景色（排查「这块白是谁给的」用，平时不用管）。
- **站姿相关的东西全部移除**（模型、代码、白名单、目录）—— 那套站姿确实做不出来，不再留入口。
- 去掉一个误打包的调试页；**README 末尾新增「第三方来源」**，列清借用过的开源项目。

**装法**：解压 → DSH 插件页「添加插件」贴文件夹路径 → 启用 → 重启一次 DSH。语音与美术都在包里，
不装本机 TTS 也有预烧语音；想让她「说新句子」才需要配一个（面板 → 语音 →「配置」）。

## 它包含什么（一个包、三个组件）

装完之后 **设置 → 插件** 里会看到「包含的组件 共 3 个」，三个可以分别停用：

| 组件 | 做什么 |
|---|---|
| `ui-cyrene-live2d` | **主插件**：Live2D 桌宠 · 整页主题（配色/水印/开屏）· 人格与世界书注入 · **351 条预烧语音**（32k opus；可接本机 TTS 现场合成）· 关系记忆 · 自我认知 · 余额与账本 · 米游社自动签到 · 面板里的语音/外观/记忆/签到设置 |
| `cyrene-reminder` | **副插件**：提醒。面板里写「几点提醒我什么」，到点她开口说「到时间啦 —— …」并播语音；数据在 `reminder.json`，停用它不影响桌宠 |
| `cyrene-notes` | **副插件**：便签。点「收当前剪贴板」把报错 / 代码片段 / 一句话存下来（自动分类、可复制可删）；数据在 `notes.json`，停用它不影响桌宠和提醒 |

两个副插件的路由各自独立（`/cyrene-reminder/*`、`/cyrene-notes/*`），都可以单独停用。

## 安装

### 方式 A：让 DSH 自己装（推荐）

1. 打开 **设置 → 插件 → 添加插件**
2. 把 `dsh-plugin-cyrene-live2d-0.2.6.tgz` 的**绝对路径**粘进去（例如 `D:\下载\dsh-plugin-cyrene-live2d-0.2.6.tgz`）
3. 点安装，等它跑完 → **重启 DSH**

> 它底层用 pnpm 装，会自动写进 `dsh.profile.bundles`，你不用改任何配置文件。
> 注意：`.zip` 这条路装不了（pnpm 不认 zip），只能用下面的方式 B。

### 方式 B：手动解压

1. **解压**到 `~/.dsh/profiles/desktop/node_modules/dsh-plugin-cyrene-live2d/`
   （解压出来顶层只有一层目录 `dsh-plugin-cyrene-live2d-0.2.3/`，把它改名成上面的样子放进 `node_modules`）
2. 打开 `~/.dsh/profiles/desktop/package.json`，在 `dsh.profile.bundles` 数组里加一行：

   ```json
   "dsh-plugin-cyrene-live2d"
   ```

3. **完全退出 DSH 再启动**（bundles 只在启动时读，热重载不管）

无论是哪种方式：**都不需要 `npm install`** —— 本插件没有 npm 依赖，前端依赖已随包带上。

> 装完可以在设置 → 插件里看到它；侧边栏会多一个「小昔涟」按钮，点开就是设置面板。

## 首次启动

- 第一次启动会自动写入 `~/.dsh/cyrene-live2d/prefs.json`（人设 + 主题开关）。
  你的 `prefs.json` 已存在时**不会被覆盖**。
- **米游社签到**：面板 → 米游社 → 扫码登录（首次会创建 `~/.dsh/cyrene-live2d/mys/`）。
  未登录时调度器静默跳过，不会报错；登录后自己决定每天什么时候签，漏了会补。
- 登录态是**你自己的**，包里的那个是空的 —— 别复用别人的。

## 怎么和她玩

| 操作 | 她会做什么 |
|---|---|
| **单击** | 摸摸头 → 说一句（深夜走深夜台词池） |
| **双击** | 做个小动作 + 说一句闲话 |
| **三击** | 报今天花了多少 |
| **在模型上部往下划** | 摸头专用反应 |
| **按住拖动** | 把她挪到任意位置（位置会记住） |
| **右键** | 菜单：切换模型 / 设置 / 让她先让开 |
| **侧边栏「小昔涟」** | 打开设置面板 |

**设置面板里能改什么**

- **主视图**：她在不在 / 大小（滑杆）/ 语气开关 / 位置复位
- **外观**：主题（打开二级页：配色 · 强度 · 氛围层 · 对话水印 · 开屏 · 品牌字样）/ 开屏档位 / 表情大小 / 水印
- **语音**：现场合成能不能用（体检）/ 路径配置
- **模型**：昔涟 / 键盘版 / Q 版（切换后重载她，不刷新整页）
- **记忆 / 提醒 / 便签 / 米游社**：各自一屏

> 主题的 16 个开关都在「外观 → 主题」里；想一键回到素颜，地址栏后面加 `?cyrene=off`。

## 人设与世界书（注入）

她在对话里「像昔涟」靠两样东西注入 system prompt，都在**设置 → 插件 → 小昔涟 → 面板 → 人格**里能看到与编辑：

| 注入什么 | 内容 | 在哪 |
|---|---|---|
| **人设** | 3249 字的角色设定（口吻、分寸、边界、怎么自称） | 面板 → 人格（可直接改、保存生效） |
| **世界书** | **61 条翁法罗斯设定**（三形态、称呼、关系、地点……），按你这段对话的关键词挑几条注入，常驻块 ≤1800 字、命中块 ≤3000 字 | 包内 `lib/worldbook/data/`，改 md 就生效（5 秒内自动重读） |

两条设计说明：

- **会话内冻结**：同一会话里世界书只算一次，换会话才重算 —— 为了保住 system prompt 的前缀缓存（缓存命中约是新输入价格的 1/10）。
- **只参考、不当事实乱编**：设定里没有的，她会说「这个人家不确定哦」，不会硬编。

验证方法：问她一句「白厄是谁」/「哀丽秘榭在哪」—— 答得出说明世界书命中了；完全不知道，多半是那段对话里没出现触发词。

## 语音（可选）

**没有 GPT-SoVITS 也能用。** 包里带 351 条预烧语音，只是不能现场合成新句子
（带变量的句子，比如任务进度，就只能出文字）。

想接本机 TTS（GPT-SoVITS / OpenAI 兼容实现都行）：
1. 装好 GPT-SoVITS（`api_v2.py` 能跑起来）
2. 面板 → 语音 →「配置」→ 自动探测 / 手填 Python、程序目录、依赖目录、`*-infer.yaml`
3. 保存并重启，点「体检」听一句就知道通没通

## 数据与隐私

全部数据都在 **`~/.dsh/cyrene-live2d/`**：

```
memory.json      关系记忆          prefs.json       偏好 + 人设
usage.json       用量              ledger.json      每日账本
selfnote.json    自我认知          tts.json         语音配置
custom/          你上传的表情包      mys/             米游社登录态
```

- **不联网上传**任何数据
- 米游社 Cookie 以**明文**存在本地 —— 自动签到必须如此，别把这一份发给别人
- 升级时只需要覆盖代码（`lib/` `assets/`），**不要动这个目录**

## 常见问题

| 现象 | 先看这里 |
|---|---|
| **她不出来** | 侧边栏有没有「小昔涟」按钮 → 有就点开面板看「她在不在」；没有就是插件没启用（设置 → 插件） |
| **完全没声音** | 面板 → 语音 →「体检」。没装本机 TTS 时**只有预烧的 351 条**会出声，新句子只有文字 —— 这是设计，不是坏了 |
| **主题没生效 / 整页还是白的** | 外观 →「主题」→ 打开二级页看「启用」是不是开；地址栏有没有 `?cyrene=off` |
| **切到键盘版后，摸头/表情没反应了** | 素材限制：键盘版模型没有表情和动作，只有按键手。切回「昔涟」即可 |
| **升级后我的数据还在吗** | 在。数据都在 `~/.dsh/cyrene-live2d/`，升级只覆盖 `lib/` 和 `assets/` |
| **想彻底卸载** | 设置 → 插件 → 停用；需要的话再删掉 `~/.dsh/cyrene-live2d/`（**删了记忆和账本就没了**） |

## 升级

覆盖 `lib/` 与 `assets/` → 重启 DSH。

新版人设**不会**自动覆盖你现有的 `persona`（这是有意的，免得洗掉你自己改过的版本）。
想换新人设：面板 → 人格，手动粘贴。

## 用的是哪一版

面板最底下一行会印出版本号（`小昔涟 v… · 模型 Cyrene`）。
报问题的时候带上这一行和端口号会快很多。
